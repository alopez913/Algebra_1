Section 1.1 — Evaluating Algebraic Expressions

Big Ideas Learning · Algebra 1 · Chapter 1

OAS: A1.A.3.4 2 Days · 45 min each
At a Glance
Evaluate algebraic expressions
algebraic expression
A1.A.3.4
✦ Success Criteria
  • Evaluate algebraic expressions for given replacement values of the variables.
  • Evaluate expressions involving absolute value, square roots, and order of operations.
  • Evaluate expressions with two or more variables using substitution.
  • Evaluate expressions to solve real-life problems.
Vocabulary
algebraic expression

An expression that may contain numbers, operations, and one or more variables. To evaluate, substitute the given values and simplify using order of operations.

Daily Pacing
📅 Day 1 One-Variable Expressions
I Do — Direct Instruction ~18 min

Example 1: Evaluating Expressions with One Variable

Evaluate for \(x = 8\):

(a)\(x + 4\) (b)\(|4 - x| + 2\) (c)\(\sqrt{2x} - 3\)

Example 2: Evaluating Expressions with Two Variables

Evaluate for \(x = -3,\ y = 4\):

(a)\(2x + 3y\) (b)\(\dfrac{x+y}{x^2}\)

⚠️ Introduce only — students will not practice independently today.

We Do — Guided Practice ~10 min

Extra Example 1 — evaluate for \(x = 4\):

(a)\(x - 1\) (b)\(2 - |3 + x|\) (c)\(\sqrt{9x} - 5\)

Extra Example 2 — evaluate for \(x = -4,\ y = 5\):

(a)\(5x + 3y\) (b)\(\dfrac{y^2}{y-x}\)

Students try each part, then reveal and discuss.

You Do — Self-Assessment ~10 min

Self-Assessment Problem 1 only

\(2\sqrt{m+31};\ m = -6\)

⚠️ Skip Problems 2, 3, 4 — two or more variables; saved for Day 2.

Assignment (in class) ~9 min

Exercises 1, 2, 3, 4

Single-variable substitution. Directly mirrors Example 1.

📅 Day 2 Multi-Variable & Complex Expressions
Warm-Up Review ~5 min

Quick two-variable problem revisiting Example 2.

Bridge from Day 1 → Day 2 new content.

I Do — Direct Instruction ~12 min

Example 3: Evaluating Expressions

Evaluate for \(a = \tfrac{2}{3},\ b = 9,\ c = -4\):

(a)\(2(9a^2 - 2b + 3c)\) (b)\(\sqrt{b} - 3a + 2c\)

Emphasize fractions, order of operations, and careful substitution.

Example 4: Modeling Real Life

The cost for \(a\) adults, \(c\) children, \(s\) seniors: \(9.50a + 5.25c + 7.00s\). Find cost for 4 adults, 6 children, 2 seniors.

We Do — Guided Practice ~8 min

Extra Example 3 — evaluate for \(a=16,\ b=\tfrac{3}{4},\ c=-1\):

(a)\(3(-2a + 8b - 5c^2)\) (b)\(\sqrt{a} - 4b + 5c\)
You Do — Self-Assessment ~6 min

Self-Assessment Problems 2, 3, 4

2.\(4s - t;\ s=\tfrac{3}{4},\ t=\tfrac{1}{2}\) 3.\(1 - |a| \div b;\ a=-\tfrac{2}{3},\ b=2\) 4.\(5s - \sqrt{r} \div 6;\ r=9,\ s=1.5\)
Assignment (in class) ~12 min

Exercises 7, 8, 9, 10, 13, 15, 18

Two-variable (7–10) + multi-variable (13, 15) + real-life modeling (18). Reinforces Examples 2, 3, and 4.

Exit Ticket / Mini-Assessment (end of Day 2)
Problem 1
Evaluate \(|-3x + 7|\) for \(x = 6\).
Answer: 11
Problem 2
Evaluate \(-2(\sqrt{a} + 4b - 3)\) for \(a = 16,\ b = \tfrac{3}{4}\).
Answer: −8
Problem 3
Find cost using \(12a + 7.25c + 9.75s\) for 2 adults, 5 children, 4 seniors.
Answer: $99.25
